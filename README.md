# 📚 Research Paper Implementations

A collection of **deep learning research papers implemented from scratch in PyTorch**.

This repository is my hands-on journey to understand important research papers by going beyond reading them — implementing the mathematics, architecture, training process, and experiments myself.

---

## 🎯 Goal

The goal of this repository is to develop a deeper understanding of modern Deep Learning by:

- 📖 Reading research papers
- 🧠 Understanding the core ideas
- 📐 Understanding the mathematics
- 💻 Implementing the architecture in PyTorch
- 🧪 Training the models
- 📊 Evaluating the results
- 🔬 Running my own experiments
- 📝 Documenting what I learn

> **Read → Understand → Implement → Experiment → Learn**

The goal is **not simply to reproduce someone else's implementation**.

For each paper, I try to understand:

```text
Research Paper
      ↓
Problem
      ↓
Main Idea
      ↓

      ↓
Architecture
      ↓

      ↓
Training
      ↓
Evaluation
      ↓
Experiments
      ↓
